# Cart-Abandonment-Analysis

This project is focused on the identifying Categories and Brands and their cart abandonment using SQL for data simplification and Tableau to gain insights.

---

### Methodology 
- **Step 1 (SQL):** Performed data cleaning and aggregation to isolate direct purchases and purchases via cart and exported CSV.  
- **Step 2 (Tableau):** Illustrated the funnel via cart and direct purchases to identify the categories, brands and Conversion % for each of them.
[public.tableau.com/app/profile/sumit.singh4638/viz/CartAbandonAnalysis/Dashboard1](https://public.tableau.com/app/profile/sumit.singh4638/viz/CartAbandonAnalysis/Dashboard1)

---

## Data being captured
- No. of views, cart adds, direct purchases and purchases via cart
- Categorised and Filtered by Category Group, Category Code and Brand
- Visualisation of both the funnels (View -> Purchase & View -> Cart -> Purchase)
- Table which highlights the direct purchase % and via cart purchase % for each Category Group

---

## Insights gained
- Medicine category has the highest direct purchase conversion rate and 0% via cart purchase
- Electronics should offer more photos and details about the products as it has the highest via cart purchase conversion rate
- More focus should be given to make the funnel simpler by integrating direct purchase option on all product lines without going to cart
